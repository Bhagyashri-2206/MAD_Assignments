# 💧 AquaRitual – Smart Water Reminder App

**AquaRitual** is an Android application designed to help users maintain healthy hydration habits by tracking their daily water intake and sending timely reminders to drink water.

The app calculates a personalized daily water intake goal based on the user's weight, gender, and activity level. It also allows users to record their water consumption and monitor their hydration progress.

## ✨ Features

- 💧 **Personalized Water Goal:** Calculates the daily water intake target based on user details.
- ⏰ **Smart Water Reminders:** Sends regular reminders to drink water.
- ➕ **Quick Water Tracking:** Allows users to record water intake with a single tap.
- 📊 **Daily Progress Tracking:** Helps users monitor their hydration progress.
- 📜 **Water Intake History:** Keeps track of previously recorded water consumption.
- ⚙️ **Customizable Settings:** Allows users to manage reminder preferences.
- 📱 **Simple User Interface:** Provides an easy-to-use and user-friendly design.
- 🔔 **Reminder Notifications:** Helps users stay consistent with their hydration routine.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **UI Design:** XML
- **Development Environment:** Android Studio
- **Database:** Firebase Realtime Database
- **Android Platform:** Android SDK
- **Progress Visualization:** Donut Progress

## 📱 Application Workflow

1. Open the AquaRitual application.
2. Enter personal details such as gender, weight, and sleep schedule.
3. Get a personalized daily water intake goal.
4. Receive reminders at regular intervals.
5. Record water consumption using the **+ Drink** option.
6. Monitor daily progress and view water intake history.

## 🚀 Getting Started

### Prerequisites

- Android Studio installed on your computer.
- Android SDK configured.
- Java development environment.
- Firebase project configured for Realtime Database.
- Android device or emulator.

### Installation

**1. Clone the repository**


git clone https://github.com/YOUR-USERNAME/AquaRitual.git

**2. Open the project**

Open Android Studio and select **Open**. Choose the cloned AquaRitual project folder.

**3. Configure Firebase**

Connect the project to your Firebase project and add the required `google-services.json` file to the app module if it is not already included.

Configure Firebase Realtime Database according to your project setup.

**4. Sync the project**

Allow Android Studio to download the required dependencies and complete Gradle synchronization.

**5. Run the application**

Connect an Android device or start an emulator, then click the **Run ▶** button in Android Studio.
